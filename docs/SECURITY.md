# Seguridad y límites
Cliente hostil: recalcular score con config y eventos, no confiar en normalizedScore ni user_id enviado. Evaluador actual valida forma/límites de evidencia y normaliza; NO demuestra que el input proviene de una persona. Bots/replays fabricados pueden pasar. Attestation/rate limits/anomalías son capas posteriores, no garantía.
Auth JWT verificado en servidor; identidad derivada del token. No user_metadata para roles. Anonymous Auth no evita cuentas múltiples: quotas/CAPTCHA y vinculación de cuenta son necesarias. Refresh tokens en Keychain/Keystore; no PlayerPrefs.
RLS en tablas expuestas y preferentemente privadas. Sin INSERT/UPDATE cliente para attempts/scores/rewards. Funciones privilegiadas internas con grants restringidos y search_path explícito. Revocar EXECUTE PUBLIC por defecto. No vistas que salten RLS. service_role solo en secretos de funciones.
Start consume intento en transacción antes de devolver config. Cerrar app no restaura intento. Reintentar misma petición no consume otro. Submit idempotente, control de dueño/config/version/ventana y tres rounds exactos. Recovery no puede distinguir perfectamente crash de force quit: definir política sin reset de configuración ni reloj.
Reload deshabilitado inicialmente. Requiere SSV Google verificada, transaction_id único, custom_data ligado al usuario/Shot/nonce y ventana temporal. Callback cliente nunca concede recompensa. Eventos tardíos muestran pendiente; sin grant duplicado.
Invitaciones: token aleatorio de alta entropía, hash en DB, expiración/rotación/rate limit, no datos sensibles en URL. No auto-join sin confirmación del usuario invitado.
Minimización: sin contactos/GPS. Definir conservación de eventos, anonimización, exportación y borrado coordinado de Auth/DB/storage/tokens. Borrado no invalida automáticamente JWT: revocar sesiones y verificar estado en operaciones sensibles.
No publicar hasta probar RLS con usuario A/B/anon, acceso previo a scores, concurrencia de start/submit, invalidación y SSV replay; auditar advisors. Estos tests DB aún NO se han ejecutado.

# Dirección candidata
Digital Toy, portrait, objetos grandes con materiales mates, iluminación suave y fondo limpio. Tipografía grande, pocas palabras y una acción primaria. Sin armas ni casino. Paleta y logo pendientes de aprobación visual.
Home: identidad Shot + tres rounds + duración + START; debajo participación Crew sin score. HUD mínimo con progreso 1/3 y tiempo. Transiciones máximo 1–2s; assets precargados.
Results: total, desglose de rounds, Crew y comparación world real con indicador provisional. Estado vacío explícito; conexión fallida no simula éxito. Estados de loading/error/retry/locked previstos.
No depender solo de color para éxito/error. Audio/haptics opcionales, reduced motion, safe area. Gestos dentro de zona segura para no activar navegación del SO. Contraste/tap targets se verificarán al crear escenas.
